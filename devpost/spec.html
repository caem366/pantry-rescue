Real retailer: Kroger API

Requires the user's registered developer app, OAuth consent, and configured store location. Searches actual catalog results and requests UPC-based cart additions.

Fallback: Demo Market

Uses sample products and simulated cart data. It is functional for testing but never changes or claims to change a real retailer cart.

Handoff boundary

Open Kroger cart → is for manual user review, not API verification. Demo Market ends with Review cart →. Checkout, payment, and order placement are unavailable.
